# TD_Saasplatform_BE_nodejs_FE_reactjs_FE_angularjs-

Multi-Product SaaS Platform: one Node.js (Express) backend with two API
namespaces (`/api/customer/*` public, `/api/admin/*` internal), a React
customer app that only calls the customer namespace, and an Angular
admin app that only calls the admin namespace.

See ARCHITECTURE.txt for build commands and the full architecture.

Branches: `saasplatform_BE_nodejs<18|20|22|24>_FE_reactjs<18|20|22|24>_FE_angularjs<16|17|18|19>`
(64 combinations of Node.js × React × Angular versions).
